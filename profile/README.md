## Perceptle

[Perceptle](https://theperceptle.com/) is a daily perception game.
Count dots, predict a landing, match an angle, keep a rhythm and split a line.
Five quick challenges on one shared puzzle, new at 00:00 UTC.

**Play**

- [Daily Perceptle](https://theperceptle.com/)
- [Perceptle Unlimited](https://theperceptle.com/unlimited): fresh practice rounds

**Open source**

[perceptle-rules](https://github.com/Perceptle/perceptle-rules) contains the
scoring, error measurements, UTC calendar, statistics and share formatting used
by theperceptle.com. TypeScript, MIT licensed, with no runtime dependencies.
